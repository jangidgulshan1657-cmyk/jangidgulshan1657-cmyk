# Hi, I'm Gulshan

Self-taught developer based in Jaipur, India — no CS degree, learning by building.

## What I'm doing

Transitioning full-time into software, focused on automation, AI integration, and eventually building and freelancing with agent-based tooling. Right now that means core Python fundamentals and shipping small, complete tools — not tutorials.

## Currently building

**[Smart Task Manager](link-to-repo)** — a CLI task manager that grew, feature by feature, from a basic in-memory list into a tool with live weather-based risk advisories and a runtime-configurable rules engine. Built entirely with the Python standard library.

## How I work

- Build in public, incrementally — every commit is a real, tested addition.
- Standard library first; reach for a dependency only with a real reason to.
- Verify with actual runs and real output, not assumptions about what the code "should" do.

## Stack

Python (current focus), JSON-based persistence, REST API integration via `urllib` — moving toward LLM API integration next.
